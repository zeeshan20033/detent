# Detent

A small Mac menu bar app that makes scrolling feel mechanical. Every few points
of scroll, your trackpad taps and a short click plays, like a notched wheel.

## Install

You need a Mac with macOS 14 (Sonoma) or later. Haptics need a Force Touch
trackpad, which most MacBooks from 2016 onwards have. The sound works on any Mac.

Claude can't turn on Accessibility for you. That's the one step you do yourself,

### Install with Terminal

Open **Terminal**, paste all of this and press Return:

```bash
cd "$(mktemp -d)"
curl -fL -o Detent.zip https://github.com/zeeshan20033/detent/releases/download/v1.0/Detent-1.0.zip
ditto -x -k Detent.zip .
pkill -x Detent || true
rm -rf /Applications/Detent.app
mv Detent.app /Applications/
xattr -dr com.apple.quarantine /Applications/Detent.app
open /Applications/Detent.app
```

This downloads the app, replaces any older copy in Applications, and opens it.
The `xattr` line removes the flag macOS uses to block apps that Apple hasn't
notarized, so only run it if you trust this app.

### Install by hand

1. Download `Detent-1.0.zip` from the
   [latest release](https://github.com/zeeshan20033/detent/releases/latest).
2. Unzip it and drag **Detent** into your **Applications** folder.
3. Open the app once. When macOS blocks it, go to
   **System Settings → Privacy & Security** and click **Open Anyway**.

### Allow Accessibility

Turn on **Detent** under
**System Settings → Privacy & Security → Accessibility**. macOS only reports
scrolling across all apps to apps that have this permission.

Detent starts working a moment after you allow it. Look for the waveform icon in
your menu bar.

## Settings

Click the waveform icon and choose **Open Detent…**.

| Section | What you can change |
|---|---|
| Sound | Turn the click on or off, pick one of seven voices, and set a volume that's separate from your Mac's |
| Haptics | Turn the tap on or off, and pick Light, Medium or Strong |
| Feel | How often it clicks, and whether it keeps clicking while a page coasts |
| Gestures | Clicks on pinch, rotate, three-finger swipe and force click |

Turn on **Open at login** to have it start with your Mac.

## Known limits

- **It keeps clicking at the end of a page.** macOS doesn't tell apps when a page
  has stopped moving.
- **Three-finger swipes usually do nothing.** macOS keeps Mission Control and
  full-screen swipes to itself. The setting can only work if
  **Swipe between pages** uses three fingers in Trackpad settings, and that
  setup hasn't been tested.
- **Double pulse can feel like a double tick,** so it's off by default.
- **It has only been tried on one Mac:** an M4 MacBook Air on macOS 26.

## Privacy

Detent uses Accessibility access to watch scroll and gesture movement. It makes
no network connections. It writes a small debug log of scroll and gesture
activity to `/tmp/detent-debug.log`, which stays on your Mac.

## Uninstall

Quit Detent from its menu, delete it from Applications, and remove it from the
Accessibility list in System Settings.

## Build from source

You need the Xcode command line tools (`xcode-select --install`).

```bash
./build.sh
open /Applications/Detent.app
```

`build.sh` installs to `/Applications`, replacing any copy already there. It
signs the app so that its Accessibility permission survives rebuilds, which means
any app signed with the same identifier would pass the same check. That's handy
while developing, but it's weaker than a release build.

`tools/package.sh` builds the universal release zip in `dist/`, using the
stricter default signature. The click sounds are generated by
`tools/make_sounds.py`.
